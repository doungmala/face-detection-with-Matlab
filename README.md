# face-detection-with-Matlab

หน้าที่หลักของไฟล์สำคัญในโฟลเดอร์มีดังนี้ครับ:

demo.m หรือ example.m: ไฟล์หลักสำหรับรันตัวอย่างโปรแกรมทั้งหมด เพื่อดูการทำงานของการตรวจจับหรือจดจำใบหน้า

CreateDatabase.m: ใช้สำหรับสร้างฐานข้อมูล (Database) ของภาพใบหน้าบุคคลที่ต้องการให้ระบบจดจำ

EigenfaceCore.m: หัวใจสำคัญของอัลกอริทึม Eigenface (Principal Component Analysis - PCA) ใช้สำหรับคำนวณและเปรียบเทียบใบหน้า

Recognition.m: ไฟล์สำหรับประเมินและทายว่าใบหน้าในภาพทดสอบตรงกับใครในฐานข้อมูล

test_webcam.m / test_video.m: ใช้สำหรับทดสอบระบบแบบ Real-time ผ่านกล้องเว็บแคมหรือไฟล์วิดีโอ
